## Projetos em produção

Sistemas que desenvolvi e mantenho para a operação de logística. O código é de uso interno da empresa e não é público; as telas, com dados fictícios, estão no [portfólio](https://julio-portifolio.pages.dev/).

| Projeto | O que resolve | Stack |
| --- | --- | --- |
| **GestFrota** | Custos da frota (manutenção, combustível, custos fixos) em dashboards em tempo real. Motorista lança o abastecimento pelo celular e o km/L é calculado por viagem | React 19, FastAPI, Supabase, PostgreSQL, Recharts |
| **Rastreio** | Recebimento, saída e entrega de cargas por nota fiscal: bipagem de NF-e via API, saldo de peso garantido no banco e baixa com foto do canhoto | Python, Django, PostgreSQL, S3, django-axes |
| **ProdManutenção** | Manutenção preventiva industrial: OS abertas e concluídas pelo celular com QR Code, e geração automática das preventivas a partir do plano | React 19, FastAPI, Supabase, RLS, Render |
